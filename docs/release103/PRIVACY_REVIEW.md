# PRIVACY REVIEW

Se mantiene el diario local y la separación por usuario. El panel de estado devuelve booleanos de configuración y no claves ni fotos. El selector Android exporta el diario sólo a petición del usuario. La expiración del token conserva la identidad local para el desbloqueo posterior. No se ha incorporado ningún SDK publicitario ni transferencia comercial de datos sanitarios. Revisión de privacidad completa y pruebas de borrado pendientes.
